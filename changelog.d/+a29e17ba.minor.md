A box that `Part.infer_bbox_from_sdf` or `tighten_part_bbox` persists into `metadata["bbox"]` now carries a `metadata["bbox_basis"]` record of what it was inferred over, and sampling, export, metric compilation, shader emission and motion bounds set the box aside once the part has changed under it, so a stale box no longer cuts off a grown part. `tighten_part_bbox` writes the record only when it tightened inside a box derived from the part; tightened inside an authored or unlabelled box or `bbox_half_size`, the box keeps that label. An authored or unlabelled box is used as stored, as before. `sdf.bbox.stored_bbox` and `stored_bbox_status` expose the check.
